# 固定したBoolean介入解除に必要な追加観測14bit

版：1.0.0（2026-11-04）。[English](README.md)。[第三者の権利と出典](THIRD-PARTY-NOTICES.md)。

凍結した56式と指定の二段階操作で、**指定の解除ガードに必要な最小追加観測数は14bit**となる。37候補bitから観測集合Sを一度だけ選び、第2段で五つのreadoutがE1となり、S上の現在値が参照状態と一致した最初の時点で、四bitの固定を全て解除する。このガードについて、全prefixの安全、全公平経路での有限解除、解除後のE1維持を求めた結果である。別のガード、観測履歴を使う方策、別の介入までを最適化したものではない。[固定した仕様](SPEC.md)。

五readoutの順序は `(AJ_b1, AJ_b2, FA_b1, FA_b2, FA_b3)` で、M3は `(0,0,1,1,1)`、E1は `(1,1,0,0,0)` を表す。unforcedな固定点は、固定した環境の下で介入のclampをかけず、元の規則を満たす不動点である。14は、この五readoutに追加するbit数である。環境の十入力、その下での全M3初期固定点二つ、参照状態を固定する。安全は各prefixでAJ=00又はFA=000を保つという模型内の条件を指す。非同期の一bit更新、許容される閾値状態、bit単位の公平性も仕様の一部で、公平性から一様な待ち時間は出ない。介入数の最小化や、実細胞への安全保証ではない。

固定する操作対象はECad・PAK・FAK_SRCの両閾値bitである。ECadを最初は0とし、FA=000で直ちに1へ切り替える。他の三bitは解除ガードまで0を保つ。更新は一自由bitずつで、値が変わらない自己更新も許す。

十四本の許容な有限反例が、互いに交わらない十四個の非空な差集合を持つ。13bit以下の選択は少なくとも一つを見逃し、安全でない解除を許す。一方、指定した14bitの組は十分であり、**最適な14bitの組はこれ一つだけである。** どの一bitを削っても13bitになるので、下界から直ちに失敗が従う。証明書は、そのときに効く反例を指定する。十四の差集合全てと交わる14bitの108候補は全て解除条件へ到達できるが、107候補には、その経路で初めてE1になった状態で解除され、その後有限回の更新でE1を失う経路がある。残る一組は全経路・公平性の検査を通る。より大きい全ての成功集合にも各bitが必須だという主張はしていない。[分類と主張の範囲](OPTIMAL-SET.md)。[同梱の変換器](MODEL-CONVERSION.md)がBioModelsの固定したSBMLから56式を再生成し、従来式との全局所割当ての比較記録を確認する（計1,728割当て、差なし）。下界と上界の検査には二つの方法を含めた。

- 保存した証明書の検査：Boolean制約を再構成し、70件の帰納性・ガード条件のUNSAT証明木、解除後1,024状態の不変集合などを照合する。
- 別実装のROBDD検査：固定点・全到達集合を直接求め、公平にガードを避け続ける経路がないことを確認する。第2段（コードのphase 1）12,031,132状態、解除時1,024状態は全て許容領域内にある。

一意性はROBDDの一経路で確認する。`unique_check.py`は`bdd_check.py`と下界の反例を使い、保存した分類を再計算する。別の証明書検査器は一意性を検査しない。107候補の除外はBDDの集合計算によるもので、それぞれの再生可能な経路を保存したものではない。

Linux又はmacOS、Python 3.11以降で、checkoutした一式の中から実行する。

```sh
python3 -I -B verify.py --budget-seconds 540
```

追加ライブラリ、solver、producerの再実行、ネット接続、クラウドは不要。ファイルhash、二つの検査、小さな明示グラフとの比較、改変証人の拒否を確認し、一式を書き換えない。[実行方法](VERIFY.md)、[主張一覧](claims.json)、[検証記録](VERIFICATION-RECORD.md)、[来歴](PROVENANCE.json)。

ROBDDの担当は、修正版のproducerコード・証明本文を読まずに別実装で確認した。ただし前回仕様の証明本文を既読で、修正版の仕様抜粋にも短い証明書概要が含まれた。**別担当・別実装による計算検証であり、完全に証明未読の独立導出ではない。** Leanの形式証明や人の査読でもない。その後の本パッケージ作成時にはproducer検査器を読み、公開用に手直しした。この時系列を検証記録に分けて記した。

旧仕様のFAK_SRC片bit固定は、非許容の閾値符号01を作る場合があった。本仕様は両bitを同時に00へ固定する。旧反例の5本は修正済みで、旧経路は負の対照・比較用と明記して添付した。最小値は同じ14だが、二つの操作仕様や候補集合を同一視しない。

主張は56式のbit操作・bit公平性・bit観測コストに限る。元の51多値節点での公平経路や最小観測数の同値性、一般的な新制御法、生体での効果・安全性へは広げない。

貢献は、固定した操作をいつ解除するかを判断するための、現在値の一致を使う指定ガードの最小追加観測数と、上下界・証人・検査器をそろえた有限benchmarkである。代表例として、[Mandonら（2019）](https://doi.org/10.1109/TCBB.2019.2914383)の逐次的な再プログラミング、[Weiss・Margaliot（2019）](https://doi.org/10.1109/TAC.2018.2882154)の論理積Boolean網での最小可観測性がある。ここでは介入を固定し、観測で解除時点を決める。出力列から全状態を復元する可観測性とは目的が異なる。[出典と比較](SOURCES.md)。限定した文献比較はこの位置づけを支持するが、網羅性や優先権を確定するものではない。修正版の別担当確認は上記の範囲で完了した。

本研究は、Gianluca Selvaggio・Sara CanatoらのEMT模型と論文[*Hybrid Epithelial–Mesenchymal Phenotypes Are Controlled by Microenvironmental Factors*（2020）](https://doi.org/10.1158/0008-5472.CAN-19-3147)、その[公開GINsim模型](https://ginsim.github.io/models/2020-mammal-emt-microenvironment/)を基礎とする。同梱のBoolean式は[BioModels MODEL2004040001](https://www.biomodels.org/MODEL2004040001)のSBMLから生成した。従来の比較対象は、[Hannes Klarner・Adam Streck・Heike SiebertによるPyBoolNet](https://doi.org/10.1093/bioinformatics/btw682)の[版を固定した模型集](https://raw.githubusercontent.com/hklarner/pyboolnet/866a84d57935735ea781b0cc96e6df74a3ac0b52/pyboolnet/repository/selvaggio_emt/selvaggio_emt.bnet)から得た。Laura Cifuentes-Fontanals・Elisa Tonello・Heike Siebertの[*Control in Boolean Networks With Model Checking*（2022）](https://doi.org/10.3389/fams.2022.838546)は、制御と表現型回避を扱う比較の基礎となった。今回の解除観測の仕様と証明書は本資料に定める。この分野を切り開いてきた研究者の方々に感謝し、この小さな仕事が、再検査できる具体例を一つ付け加えられたなら幸いです。謝意は著者による確認や推薦を意味しない。[出典](SOURCES.md)。
