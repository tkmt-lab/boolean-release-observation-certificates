# Fourteen observation bits for a fixed Boolean release protocol

Version 1.0.0, 2026-11-04. [日本語](README.ja.md). [Third-party notices](THIRD-PARTY-NOTICES.md).

In one frozen 56-rule Boolean network, **14 additional observation bits are necessary and sufficient for the specified release guard** to meet the safety, eventual-release and post-release requirements. The two-stage intervention is fixed. The observation set S is chosen once from 37 candidate bits; in the second stage, all four bit clamps are released at the first state with the five-bit E1 readout and agreement with the reference state on S. This guard uses the current values on S. The result does not optimize over other guards, observation histories or interventions. [Exact specification](SPEC.md).

The five-bit readout is `(AJ_b1, AJ_b2, FA_b1, FA_b2, FA_b3)`: M3 means `(0,0,1,1,1)` and E1 means `(1,1,0,0,0)`. An unforced fixed point satisfies the natural rules under the fixed environment, with no intervention clamps. The cost counts observation bits in addition to these five readout bits. The ten environment inputs, both initial M3 fixed points under those inputs, and the reference state are fixed. Safety means AJ=00 or FA=000 at every prefix, and the E1 readout must persist after release. The asynchronous update rule, admissible threshold states and bit-fairness assumption are part of the claim. Fairness gives no uniform waiting-time bound. This is a finite model result, not a claim about interventions in cells.

The fixed intervention atomically clamps ECad, PAK and both threshold bits of FAK_SRC. ECad starts at 0 and switches to 1 when FA=000; the other three bit clamps stay at 0 until the release guard. Updates select one free bit, including self-updates that leave its value unchanged.

Fourteen admissible finite counterexamples have pairwise disjoint nonempty difference sets. Every selection of at most 13 bits misses one such set and permits a violating release. An explicit 14-bit selection is sufficient. **This optimal set is unique.** Removing any one bit leaves 13 bits and therefore fails by the lower bound; the certificate names the responsible witness. The 108 size-14 sets that hit all fourteen difference sets were exhaustively classified: all can release, but 107 admit a violating path released at a state that is the first E1 state on that path, followed by a finite continuation that loses E1. The remaining set passes the full all-path and fairness checks. This does not establish that each bit is mandatory in every successful larger observation set. [Classification and proof boundary](OPTIMAL-SET.md). The [bundled converter](MODEL-CONVERSION.md) regenerates the 56 rules from the pinned BioModels SBML and checks the recorded full local comparison with the earlier reference (1,728 assignments, zero differences). The lower and upper bounds have two complementary proof checks:

- A certificate consumer reconstructs Boolean constraints and replays saved UNSAT proof trees, including 70 induction/guard queries and a 1,024-state invariant cube.
- A separate ROBDD implementation constructs the fixed-point and reachable-state sets directly, and checks the absence of fair infinite guard avoidance. It reaches 12,031,132 states in the second phase and 1,024 release states, all admissible.

Uniqueness is checked by one ROBDD route: `unique_check.py` uses `bdd_check.py` and the lower witnesses. The saved classification is recomputed by that route; the separate certificate consumer does not check uniqueness. The 107 exclusions are BDD set results, not individually saved replayable paths.

Run the full offline verification from a checkout with Python 3.11 or later on Linux or macOS:

```sh
python3 -I -B verify.py --budget-seconds 540
```

No solver, third-party Python package, producer run, network connection or cloud account is required. The command checks file hashes, both proof routes, small-graph comparisons and damaged witnesses. It leaves the package unchanged. [Commands and expected results](VERIFY.md), [claims](claims.json), [verification record](VERIFICATION-RECORD.md), [provenance](PROVENANCE.json).

The separate reviewer wrote the ROBDD implementation and verified the revised protocol without reading the revised producer's code or proof body. The reviewer had read the earlier protocol's proof, and a specification excerpt exposed a brief revised certificate summary. This was separate-role, separate-implementation computational verification, **not fully proof-blind independent derivation**, Lean formalization or human peer review. The producer checker was subsequently read and adapted while assembling this package; the record distinguishes that later work.

The previous b1-only FAK_SRC clamp could produce the inadmissible threshold code 01. This package clamps both bits atomically to 00. Five old counterexample paths were repaired; old paths are included only as explicitly named negative/comparison fixtures. The optimum happens to remain 14, but the protocols and candidate sets differ.

The claim does not establish native 51-species multivalued fairness or optimal observation cost, establish a new general control method, or imply therapeutic effectiveness or biological safety.

The contribution is a model-specific benchmark for deciding when to release fixed controls, with matching lower and upper certificates for a specified current-value equality guard. For representative prior work, [Mandon et al. (2019)](https://doi.org/10.1109/TCBB.2019.2914383) study sequential reprogramming, and [Weiss and Margaliot (2019)](https://doi.org/10.1109/TAC.2018.2882154) study minimal observability in conjunctive Boolean networks. Here the intervention is fixed and observations decide when to release it; reconstructing the entire state from output sequences is a different objective. [Sources and comparison](SOURCES.md). The bounded literature comparison supports this positioning; it does not establish priority or exhaustive coverage. The separate-reviewer verification described above has been completed within its stated limits.

This benchmark builds on the EMT model of Gianluca Selvaggio, Sara Canato and colleagues, [*Hybrid Epithelial–Mesenchymal Phenotypes Are Controlled by Microenvironmental Factors* (2020)](https://doi.org/10.1158/0008-5472.CAN-19-3147), and its [public GINsim model](https://ginsim.github.io/models/2020-mammal-emt-microenvironment/). The bundled rules are generated from [BioModels MODEL2004040001](https://www.biomodels.org/MODEL2004040001), with all local assignments checked against the earlier [pinned PyBoolNet comparison reference](https://raw.githubusercontent.com/hklarner/pyboolnet/866a84d57935735ea781b0cc96e6df74a3ac0b52/pyboolnet/repository/selvaggio_emt/selvaggio_emt.bnet); [Hannes Klarner, Adam Streck and Heike Siebert developed PyBoolNet](https://doi.org/10.1093/bioinformatics/btw682). Laura Cifuentes-Fontanals, Elisa Tonello and Heike Siebert's [*Control in Boolean Networks With Model Checking* (2022)](https://doi.org/10.3389/fams.2022.838546) provides control and phenotype-avoidance context. I cite that work for this context; the release-observation specification and certificates are defined here.
