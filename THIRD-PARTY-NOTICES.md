# Model provenance and redistribution review

Reviewed 2026-10-26 UTC. **The model redistribution hold is resolved for this package by replacing the old bnet with a verified derivation from BioModels' CC0 source.** Publication was separately authorized by the owner on 2026-10-26. The release metadata identifies version 1.0.0 dated 2026-11-04; this rights review records the attribution and license check.

The [current BioModels terms](https://www.biomodels.org/termsofuse) dedicate the repository's encoded models and their annotations to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), and permit modification and redistribution. The full terms page was fetched successfully and inspected, not inferred from HTTP status alone. Its URL, retrieval time and byte hash are recorded in [retrievals.json](sources/retrievals.json). The website HTML is not bundled as model data.

The bundled source is `sources/Selvaggio_etal_2020.sbml` from [BioModels MODEL2004040001's download endpoint](https://www.biomodels.org/model/download/MODEL2004040001?filename=Selvaggio_etal_2020.sbml), 210,053 bytes, SHA-256 `0be06df8664e0f6e187298753703110063d533384b14f22cabd4b569af06dd65`. The [official file list](sources/files.json) supplies the same SHA-256; the [JSON metadata copy](sources/model-metadata.json), with contributor email fields omitted, identifies the model and its paper. The ordinary HTML model-record URL previously returned an error page with HTTP 200, so that response was not used as content evidence. The successful JSON and SBML responses supply the provenance here.

The bundled converter produces `inputs/biomodels-derived.bnet` solely from the SBML. All 56 functions agree with the earlier reference over all 1,728 local Boolean assignments, including inadmissible words. [Conversion convention and checks](MODEL-CONVERSION.md). The saved certificates are bound to the newly derived functions by exhaustive local semantic checks; the ROBDD verifier uses those functions directly.

The previous 2,968-byte PyBoolNet bnet (SHA-256 `7772a1a17eed3dc344941d0788e3e4458607efa6ba1c93832eeb0d40ac7d449a`) is omitted, with only [the comparison record](verification/model-comparison.json) retained. No license is newly asserted for that old serialization. Earlier bounded searches did not establish its file-level terms; the GINsim software GPL notice and PyBoolNet package LGPL classifier were not treated as licenses for every model file. [Historical licensing retrieval records](licensing/sources.json) retain that distinction.

The original model and paper are by Gianluca Selvaggio, Sara Canato and colleagues. BioModels distributes the current CC0 input; GINsim and PyBoolNet provided earlier model access and the latter provided the comparison reference. Their software and the cited paper are not bundled. Please cite the authors and distribution sources as scientific practice; no review or endorsement by them is implied. [Sources and credit](SOURCES.md).
