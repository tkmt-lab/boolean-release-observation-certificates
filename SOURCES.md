# Sources and credit

The finite benchmark uses a frozen Boolean representation of an existing model. Its observation optimum is a claim of this package, not a result attributed to the original model authors.

- Gianluca Selvaggio, Sara Canato, Archana Pawar, Pedro T. Monteiro, Patrícia S. Guerreiro, M. Manuela Brás, Florence Janody and Claudine Chaouiya. *Hybrid Epithelial–Mesenchymal Phenotypes Are Controlled by Microenvironmental Factors*. Cancer Research 80(11), 2407–2420 (2020). [DOI](https://doi.org/10.1158/0008-5472.CAN-19-3147).
- [GINsim model record](https://ginsim.github.io/models/2020-mammal-emt-microenvironment/), identifying the same paper and its model file.
- [BioModels MODEL2004040001](https://www.biomodels.org/MODEL2004040001), the source of the bundled CC0 SBML and metadata. [Derivation and comparison](MODEL-CONVERSION.md), [redistribution review](THIRD-PARTY-NOTICES.md).
- [PyBoolNet's frozen representation at commit 866a84d57935735ea781b0cc96e6df74a3ac0b52](https://raw.githubusercontent.com/hklarner/pyboolnet/866a84d57935735ea781b0cc96e6df74a3ac0b52/pyboolnet/repository/selvaggio_emt/selvaggio_emt.bnet). This is the earlier comparison reference. Its 2,968 bytes are omitted; only the full local comparison record remains. Neither that file nor the PyBoolNet implementation is bundled.
- Hannes Klarner, Adam Streck and Heike Siebert. *PyBoolNet: a Python package for the generation, analysis and visualization of Boolean networks*. [DOI](https://doi.org/10.1093/bioinformatics/btw682). The earlier comparison rules came from its model collection; the current bundled rules are generated from BioModels SBML. This package does not use the PyBoolNet program.
- Laura Cifuentes-Fontanals, Elisa Tonello and Heike Siebert. *Control in Boolean Networks With Model Checking* (2022). [DOI](https://doi.org/10.3389/fams.2022.838546), [preprint](https://arxiv.org/abs/2112.10477). I cite this work for control and phenotype-avoidance context; the release-observation specification and certificates are defined here.


- Hugues Mandon, Cui Su, Jun Pang, Soumya Paul, Stefan Haar and Loïc Paulevé. *Algorithms for the Sequential Reprogramming of Boolean Networks*. IEEE/ACM Transactions on Computational Biology and Bioinformatics 16(5), 1610–1619 (2019). [DOI](https://doi.org/10.1109/TCBB.2019.2914383), [author-hosted paper](https://satoss.uni.lu/members/jun/papers/TCBB19.pdf), [author bibliography](https://satoss.uni.lu/members/cui/publications.php). It treats sequential temporary or permanent perturbations; this benchmark instead fixes the intervention and minimizes observations for its release guard.
- Eyal Weiss and Michael Margaliot. *A Polynomial-Time Algorithm for Solving the Minimal Observability Problem in Conjunctive Boolean Networks*. IEEE Transactions on Automatic Control 64(7), 2727–2736 (2019). [DOI](https://doi.org/10.1109/TAC.2018.2882154), [author preprint](https://arxiv.org/abs/1706.04072v2), [author bibliography](https://eyal-weiss.github.io/publications/). Its observability objective reconstructs the full state from output sequences in conjunctive Boolean networks. The present guard uses current observations to decide release and does not require full-state reconstruction.

These representative references were checked on 2026-10-28. For Mandon et al., the author-hosted abstract/introduction and author/institutional bibliographies were inspected. For Weiss and Margaliot, the author preprint's definition and introduction and the author bibliography were inspected. The latter's arXiv journal-reference field gives 2018, whereas the author bibliography gives the 2019 journal publication; the citation above uses the journal year. This is a bounded comparison, not a full-text novelty review of these papers.

I thank the original authors and maintainers. The original paper, software and services are not bundled; their names are used for attribution. Temporary and sequential control, phenotype avoidance, model checking and measured-node selection have substantial prior literature. A bounded literature comparison supports the benchmark's limited positioning without establishing priority or exhaustive coverage. Model correspondence beyond the stated bit protocol and human peer review are outside the saved computational checks.
